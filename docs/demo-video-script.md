# Demo Video Script — Searchy + TSP + Firecrawl Overlay

Implements the demo-video plan (charter v3 "we make demo videos too").
Product language throughout: measured claims, credit/cost framing, no
research vibes. Target length: 3–4 minutes total, three acts.

Recording assets (all committed or generated by one command):

```bash
# Act 1 — Searchy money plot + GIF (already committed)
experiments/results/figures/m6.6-sabotage.png   # the money plot
experiments/results/figures/m6.6-sabotage.gif    # the reroute, animated

# Act 2 — TSP colony GIF + convergence (one command after the M4-L run)
uv run python -m searchy.tsp_viz_demo           # writes figures/ (see below)

# Act 3 — Firecrawl overlay (runs from fixtures; needs the approved recording)
```

---

## Act 1 — The router that learns from its own traffic (~75s)

**[0:00]** Screen: `m6.6-sabotage.gif` playing on loop (left), one-line
overlay: "A search agent that routes queries like an ant colony."

**[0:10]** VO: "This is Searchy — a search agent that picks tools for
every query using pheromone learning. Each query is an ant: it prefers
tools that recently produced good results, and it ignores the marketing
and trusts experience."

**[0:25]** Screen: money plot PNG, cursor to the vertical line at
query #50. VO: "At query fifty we sabotage its favorite tool — quality
drops 95%, latency triples. Watch the traffic share: the colony notices
from realized rewards alone and reroutes. The baseline that trusts
advertisements never recovers — it eats the damage forever. Measured,
five seeds: post-event reward plus 0.035 for the colony, minus 0.129
for the static baseline."

**[0:55]** Screen: heatmaps PNG. VO: "And it routes differently per
query type — factual queries to web search, math to the vector DB,
summaries to the knowledge base — all learned, none programmed."

## Act 2 — Same algorithm, the classic benchmark (~75s)

**[1:15]** Screen: `tsp-colony.gif` (ants constructing tours on eil51).
VO: "The routing algorithm is Ant Colony Optimization. Before claiming
anything about it, we put it on the canonical traveling-salesman
benchmarks — 51 to 101 cities, thirty seeds each, equal compute budget
for every method."

**[1:35]** Screen: convergence plot. VO: "Plain Ant System lands within
[XX]% of the known optimum, median over thirty seeds. Adding the
pheromone-bounds variant and a cheap 2-opt refinement gets to [XX]%.
Every number in the table ships with a Wilcoxon p-value — one command
reproduces all of it."

**[2:05]** Screen: the M4-L table (CSV rendered). VO: "The point isn't
beating specialized TSP solvers — it's that when we say the router
learns, we can prove it on ground truth where the optimum is known."

## Act 3 — Spending real credits, deliberately (~75s)

**[2:30]** Screen: overlay demo plot (traffic share + cumulative credits).
VO: "The same router, now spending real money: each Firecrawl call —
search, map, scrape — costs credits. We recorded a real query session
once, then replayed it thirty times: the colony learns which tool each
query type needs, and the adaptation moment shows it shifting traffic
when a domain's quality changes."

**[2:50]** Screen: cumulative credit curves. VO: "Versus static routing
policies, pheromone routing spent [X]% fewer credits at equal or better
answer quality — [p-value], thirty seeds, replayed from fixtures so
it's reproducible for free."

**[3:10]** Close: repo README on screen. VO: "Everything's in the repo:
the router, the benchmarks, the fixture-replay harness, and the one-command
reproduction. Claims are measured or they don't ship." End card: repo URL.

## Production notes

- Voiceover: the human records; the bracketed numbers ([XX]%) get filled
  from the committed M4-L summary and the FO run — never from memory.
- GIFs play at 2–4 fps; record the screen at 30fps and let the GIF loop
  2–3 times per act.
- The sabotage money plot is the hook: it's the first thing a Firecrawl
  engineer should see (tool routing = their credit-cost problem).
- Keep the honest negatives: "the static baseline never recovers" is the
  product story; the D5 plateau detail stays in the blog, not the video.
